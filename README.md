# Madame Zhu

Сайт ресторана Madame Zhu в Перми.

Публичный сайт: https://dr4zhba.github.io/MadameZhuSite/

## Публикация

GitHub Pages публикует папку `docs/` ветки `main`. Изменения сайта загружаются в эту папку. Сборка и внешняя база данных не требуются.

## Локальный просмотр

Нужен Node.js. Запуск: `node scripts/serve.mjs`. Открыть http://127.0.0.1:4173/.

## Материалы

В меню 131 позиция. 128 карточек содержат фотографии-примеры с видимой пометкой. Три подтверждённых изображения ресторана сохранены. Источники и сведения об авторах: [docs/photo-sources.html](docs/photo-sources.html). Лицензии шрифтов Prata и Manrope находятся в `docs/assets/fonts/`.
